Why did my QR code stop working?

You scan a poster, packaging sticker, table tent, or WiFi card—and nothing useful happens. The phone shows an error, an expired-trial page, a 404, or a WiFi join that fails. It feels like the QR “broke.” In practice the square is usually still a valid barcode. Something behind it changed, or the print never scanned well.

This troubleshooting guide walks through the common causes—dead dynamic redirects, moved URLs, WiFi password changes, and print damage—and how to fix or replace the code. If you need a permanent replacement, use a free static QR generator so the payload lives in the image, not on a trial short link.

Fast triage: what does the phone actually open?

  1. Scan and read the URL or prompt carefully.
    • Unfamiliar short domain → likely dynamic / vendor redirect.
    • Your own domain with a 404 → URL moved or deleted.
    • WiFi join banner then failure → credentials changed or wrong security type.
    • “No QR found” / intermittent detect → print or contrast problem.
  2. Try a second phone (iPhone and Android). If only one device fails, update the camera app / OS before blaming the code.
  3. Try a different copy of the same design (another sticker, a digital PNG). If the file works but the sticker does not, you have physical damage or bad print settings.

Cause 1: Dynamic redirect or free trial died

Many “free QR” dashboards print a short URL owned by the vendor. Your real page sits behind that redirect. When the trial ends, the plan lapses, or the service changes policy, scanners still read the short URL—but the vendor no longer sends people onward.

Symptoms:

  • Browser opens a vendor domain you do not recognize.
  • Message about expired code, upgrade, or inactive campaign.
  • It worked for weeks, then failed everywhere at once (classic trial cliff).

What to do:

  • Check that product’s official Support / help center for trial and expiration terms (policies differ; do not assume).
  • You generally cannot revive someone else’s short link from the outside.
  • Replace printed materials with a static QR that encodes your URL directly—or move to a paid dynamic contract you trust and reprint once.
  • Deep dive: QR code expired after free trial and QR codes that never expire.

Important: free static codes (payload in the image) do not share that trial clock. Do not conclude that “all free QR codes expire”—that narrative belongs to dynamic free trials and short-link failures.

Cause 2: The URL moved

A static URL QR is permanent as a barcode—but it still opens whatever address you encoded. If you deleted /old-menu without a redirect, guests get a 404. The QR did not expire; the page left.

Fixes:

  • Restore the page, or set a 301/permanent redirect from the old path to the new one.
  • For future codes, pick stable paths (/menu, /support) and update content in place.
  • Restaurant operators: see menu QR codes that never expire.

Cause 3: WiFi password or SSID changed

Static WiFi QRs embed the SSID, security type, and password from generation time. Change the router password and old cards fail until you print new ones.

Fixes:

  • Prefer a guest network you can rotate on purpose.
  • Regenerate with the WiFi QR code generator.
  • Confirm WPA/WPA2 vs open/nopass matches the router—wrong type looks like a “broken QR.”

Cause 4: Print damage, contrast, or quiet zone

Torn stickers, low-contrast ink on colored backgrounds, glossy glare, and cropped margins all reduce scan success. The data may still be in the image; the camera cannot read it cleanly.

Fixes:

  • Reprint from SVG at adequate size with a white quiet zone.
  • Avoid stretching non-square; keep high contrast.
  • Test under the real lighting of the venue or shelf.

Cause 5: Typos and https mistakes locked in

Static means no remote edit. A missing character in the URL, http vs https on a host that refuses insecure loads, or a wrong SSID space will fail forever until you reprint.

Prevention: test the exact file you send to the printer—scan the proof, do not only eyeball the string.

How to replace a dead QR properly

  1. Decide the final destination you control (or guest WiFi credentials you accept).
  2. Generate a static code with the homepage tool—URL, Text, WiFi, Email, or Phone—no signup.
  3. Download PNG/SVG, scan-test, then replace physical pieces in one sweep when possible.
  4. If you truly need remote edits and analytics, budget for paid dynamic deliberately—read static vs dynamic QR codes first.

Soft note: the long-term home for this static workflow is qrstatic.app; use the live host when you generate.

FAQ

Can a QR code stop working even if the sticker looks fine?

Yes. Dynamic redirects, moved pages, and WiFi changes fail while the ink still looks perfect. Visual integrity ≠ destination health.

How do I tell static from dynamic?

Scan and inspect the URL. Your full domain usually means static (or a direct encode). A vendor short domain that then redirects is dynamic. Comparison: static vs dynamic.

Do free QR codes always expire?

No. Free static generators that put the payload in the image do not attach a vendor expiration clock. Free dynamic trials / short links often do stop resolving—that is a product policy, not a law of QR codes.

My packaging QR failed years later—who is at fault?

Often a manufacturer-chosen redirect service changed. Sometimes the support URL moved. Check the domain that opens. Replace future packaging codes with static URLs you control when you can.

Will regenerating the same URL create a different-looking QR?

Possibly (different error correction, colors, or library defaults). Functionally it should open the same place if the payload string matches. Retest anyway.

iPhone works but Android does not (or the reverse)

Update the OS/camera, try Google Lens or the system Wi-Fi scan for WiFi codes, and verify lighting. For WiFi, confirm security type. Persistent single-OS failures after updates may still be payload typos.

Can I fix a dead vendor short link without reprinting?

Almost never from the outside. If you still have login access to that vendor and the plan is active, you might reactivate there—check their Support docs. Otherwise reprint with a destination you own.
