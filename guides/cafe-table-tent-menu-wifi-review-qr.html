One cafe table tent, three static QR codes

Guests need three things fast: the menu, WiFi, and an easy review path. One table tent can carry all three—if each square is a static code you control, not a free-trial redirect that dies mid-season.

This is a scene layout guide for cafés and small restaurants—not a standalone menu/review landing. Deep dives: menu QR that never expires, WiFi QR generator, Google review QR (static). Below: what to encode, how to arrange three codes, and how to run them without a QR subscription.

Why three static codes beat one “magic” dynamic link

A single short URL that later routes to menu, WiFi, or a microsite is flexible—and fragile when a trial ends. Mid-rush failures still cost trust.

Static means each square carries its own payload:

CodePayloadGuest experience
MenuStable menu URL you hostOpens menu—no vendor hop
WiFiGuest SSID + password string“Join network” prompt
ReviewsYour existing Google review / Profile linkOpens your usual review flow

No account is required for those images to stay active. If one fails later, triage normally—why QR codes stop working—instead of hitting a silent trial cliff. Dynamic free trials / short-link redirects fail; free static codes with the payload in the image do not carry that clock. See never expire and static vs dynamic.

Prep the three destinations (before you design)

1. Menu URL — One evergreen path (/menu or a PDF URL you will not rename weekly); edit content in place. More: menu QR never expires.

2. Guest WiFi — Not staff/POS WiFi. Correct security type. Build on the WiFi generator.

3. Review link you already have — Encode your Google review / Business Profile URL as a static URL QR (no partnership claims). Steps: Google review QR static · tool: Google review QR generator.

Generate all three with the free static generator (client-side, no signup). Prefer SVG for print; PNG for proofs.

Layout tips for one tent, three squares

Label in words. “Menu,” “WiFi,” “Leave a review” beat unlabeled icons.

Own quiet zone per code. Do not jam edges together; white margins beat extra marketing copy.

Size for seated scan. ~30–50 cm → start 3–4 cm wide each. If the tent is narrow, stack or use two sides (menu + WiFi front; review back) instead of going below ~2.5 cm. Sizes: print size by distance.

Contrast. Dark modules on white patches—not kraft-on-kraft or photo backgrounds.

Proof under café lighting. Scan all three on iPhone and Android at a real table; prefer matte stock.

Optional: print the guest password as text beside the WiFi QR for phones that struggle with WiFi joins.

Two-sided variant: front = menu + WiFi (highest frequency); back = review + hours or Instagram handle as text (not a fourth fragile redirect).

Operations: keep the tent honest

  • Menu moves → redirect or regenerate menu QR; WiFi/review can stay.
  • Guest password rotates → reprint WiFi only via the WiFi page.
  • Review URL changes (rare) → reprint that square only.
  • Art refresh → reuse the same three SVGs; do not retype payloads from memory.

Soft note: the long-term home for this static browser-side workflow is qrstatic.app; use the live host when you generate.

What not to do

  • Staff/POS WiFi on a public tent.
  • One free dynamic short link for all three jobs unless you pay for a plan you trust—see static vs dynamic.
  • Cropping quiet zones to “make it fit.”
  • Claiming menu/review codes work offline—only the WiFi join string is offline-capable; URL codes still need data.

FAQ

Can one QR open a page with menu, WiFi password, and review buttons?

Yes—as a single static URL to a page you host. That is one square, not three. Three labeled squares reduce taps and keep WiFi working even if your site is briefly down. Pick based on how much you want to maintain a landing page.

Will three QR codes confuse guests?

Not if each has a clear text label and adequate size. Confusion usually comes from unlabeled icons or codes smaller than ~2.5 cm.

Do these café QR codes expire?

Static menu, WiFi, and review codes do not expire because of a QR vendor trial. Menu/review links still need your pages reachable; WiFi fails if you change the password. Dynamic short links on free trials are the usual “sudden death” case.

Should I use dynamic QR so I can edit the menu without reprinting?

Only if you budget for a reliable paid redirect and accept dependency. Many cafés instead keep one stable menu URL and edit the page—static tent, flexible content. More: menu never-expires guide.

What size should each code be on a standard tent?

Start at 3–4 cm wide for seated scanning. If you must go smaller, proof-scan under real lights. Full table: print size by distance.

Is a Google review QR allowed?

Encoding a review or Business Profile link you already have as a static URL is a common practice. Follow Google’s current policies for soliciting reviews; this site is not affiliated with Google.

How do I make all three codes for free?

Use the homepage static generator three times (URL, URL, WiFi)—or the dedicated WiFi tool for the network square. No signup; download PNG or SVG.
