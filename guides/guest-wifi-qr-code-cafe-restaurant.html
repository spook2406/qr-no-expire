How to make a guest Wi‑Fi QR code for a cafe or restaurant

Customers ask for the Wi‑Fi password. The room is loud, a character gets misheard, and a napkin with the passphrase gets thrown away. A guest Wi‑Fi QR code on a table tent or counter card lets a phone read the network name and password from the image and offer to join.

How do I make a guest Wi‑Fi QR code for a cafe or restaurant?

Make a guest Wi‑Fi QR by encoding the guest SSID, security type, and current password in a static WIFI: image, then print that image on a table tent or counter card, using the qrstatic.app Wi‑Fi generator in your browser with no account and no monthly fee so the finished code does not expire.

  • The encoded string looks like WIFI:T:WPA;S:GuestCafe;P:secret;;, and H:true is added only if you tick Hidden network.
  • Security is stored as WPA (the WPA/WPA2 choice), WEP, or nopass for an open network.
  • The file is static: qrstatic.app does not host a redirect, so a subscription cannot switch the printed card off.

What information goes into a cafe guest Wi‑Fi QR code?

A cafe guest Wi‑Fi QR stores the exact guest SSID, the router security type, and the current password inside the image, plus a hidden-network flag only if the SSID is not broadcast, so phones that understand the WIFI: payload can offer to join without a qrstatic account, a redirect, or a monthly subscription.

  • The SSID is trimmed, then must match the router exactly, including spaces and capitalization.
  • Backslash, semicolon, comma, and double quote in the SSID or password are escaped so the WIFI: string still parses.
  • When security is nopass, the password is omitted; otherwise the payload includes P: plus the passphrase.

Keep a guest SSID separate from staff and POS Wi‑Fi so you can rotate the guest passphrase without kicking the register offline. Leave Hidden network off unless the SSID truly is not broadcast. Most cafe routers leave the name visible.

Why should a cafe print a Wi‑Fi QR instead of telling guests the password?

A printed guest Wi‑Fi QR is better than telling guests the password in a loud cafe because the phone reads the SSID and passphrase from the image, which avoids misheard characters, and one static PNG or SVG stays the same on every table until you change the router password and reprint on purpose.

  • You own the image: PNG for a quick print, SVG when you need a sharp resize later.
  • There is no qrstatic.app login between the scan and the join.
  • A dynamic short link is a different product; compare them in static vs dynamic QR codes.

How do I create the guest Wi‑Fi QR in the browser?

Create the guest code on the Wi‑Fi QR generator by entering the SSID, choosing WPA/WPA2, WEP, or no password, typing the passphrase, ticking hidden only if needed, and downloading PNG or SVG, with generation in the browser so the SSID and password are not uploaded and no qrstatic account is required.

  • PNG widths in the tool are 256, 320, 512, and 1024 pixels, and 320 is selected by default.
  • Error correction is L (about 7%), M (about 15%, the default), Q (about 25%), or H (about 30%).
  • Quiet zone choices are 1, 2, or 4 modules, and 2 is the default.
  1. Open the Wi‑Fi QR code generator (or the WiFi tab on the homepage generator).
  2. Enter the guest SSID, choose the security type the router actually uses, enter the password, and set hidden only if needed.
  3. Generate and scan with a phone that is not already joined to that network.
  4. Download PNG for a print shop or sticker, and download SVG as the master file.
  5. Save the SVG with a one-line note: date, SSID, and who changed the router.

Treat the download like any other printed password. Do not drop the SVG in a public folder if the passphrase should stay on the premises. Rendering uses the same in-browser QR library described on About qrstatic; nothing in that step creates an account.

How large should a table-tent Wi‑Fi QR be?

Size a table-tent Wi‑Fi QR for about a 30–50 cm scan, which the qrstatic print-size guide starts at roughly 3–4 cm wide for the code square plus a clear quiet zone, while a farther counter or window sign needs a larger square and matte stock scans more reliably than glossy laminate under cafe lights.

  • The QR print size and scan distance guide starts handheld cards near 2–2.5 cm and a 1–2 m window sign nearer 10–15 cm. Those are proofing targets, not a lab certificate.

What will a guest Wi‑Fi QR code not replace on the router?

A guest Wi‑Fi QR does not create a captive portal, set bandwidth limits, or replace router security, and it will not update itself if a setup wizard renames the SSID, because it only encodes the WIFI: payload you typed—network name, security type, password, and optional hidden flag—into a PNG or SVG you download.

  • Anyone who can scan or decode the image can read the passphrase, so use a guest network rather than the staff password.
  • There is no remote kill switch: rotating access means a new file and a new print.
  • After a router “quick setup” that renames the network, generate again and scan a phone that is offline to that SSID.

What should I check before I print guest Wi‑Fi cards for every table?

Before you print a card for every table, confirm the SSID spelling, the security type, a successful scan from a phone that is not already joined, and one proof on the real stock, because a static qrstatic.app guest Wi‑Fi QR has no account and no monthly fee and keeps working only while the printed credentials still match the router.

  • Match WPA/WPA2, WEP, or no password to the router, not to a guess.
  • Test iPhone and Android if you have both, under the lighting the tent will actually sit in.
  • Keep the SVG and the one-line change note in the same folder so the next reprint is a minutes-long job.

Should I choose WPA, WPA2, WEP, or no password?
