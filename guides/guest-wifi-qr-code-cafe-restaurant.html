How to make a guest Wi‑Fi QR code for your cafe or restaurant

Customers ask for the Wi‑Fi password. Music is loud. Someone mishears a character. Another person writes it on a napkin that gets thrown away. A guest Wi‑Fi QR code on a table tent or counter card cuts that loop: phones scan, join, and you keep serving.

This how‑to shows a simple static setup for cafes, restaurants, and small shops. When you are ready to generate the image, use the free browser tool: Wi‑Fi QR code generator (no signup; the payload stays on your device).

Why a table QR beats shouting the password

  • Speed. Guests connect without hunting staff.
  • Accuracy. No more “was that O or zero?”
  • Consistency. Every table shows the same credentials until you rotate them on purpose.
  • Print control. A static code is just an image you own—PNG for quick prints, SVG for crisp re‑sizes.

If you later need remote revoke without reprinting, that is a different product class (dynamic / redirect). For guest Wi‑Fi you control, static is usually enough. Compare approaches in static vs dynamic QR codes.

What to gather before you generate

  1. SSID — the exact Wi‑Fi name guests should join (case matters).
  2. Security type — most guest networks use WPA or WPA2‑Personal. Match what the router shows, not a guess.
  3. Password — the current passphrase. Avoid temporary “demo” passwords you plan to change tomorrow unless you will reprint.
  4. Hidden network? — only tick hidden if the SSID is not broadcast. Most cafes leave this off.
  5. Where it will live — table tent, sticker by the POS, window cling, or laminate near takeaway wait. Placement drives print size.

Tip: keep a short “guest” SSID separate from staff Wi‑Fi so you can rotate guest credentials without kicking the POS offline.

Step‑by‑step: create the static guest Wi‑Fi QR

  1. Open the Wi‑Fi QR code generator on qrstatic.app.
  2. Enter SSID, choose the security type, enter the password, and set hidden only if needed.
  3. Generate and preview. Scan with a phone that is not already joined to that network.
  4. Download PNG for quick print shops or stickers; download SVG as your master file for later reprints.
  5. Save the SVG next to a one‑line note: date, SSID, who changed the router. The next password rotation will thank you.

You do not need an account. Generation runs in the browser. Treat the downloaded file like any other credential print—do not post the SVG in a public Drive folder if the password is sensitive.

Print size, contrast, and table distance

A perfect payload still fails if the printed square is tiny, low‑contrast, or wrinkled. Match module size to how guests hold their phones:

  • Table tents — phone is usually close; a modest square with a clear quiet zone works.
  • Counter or window — guests stand farther back; enlarge the code and keep the surrounding panel uncluttered.
  • Laminate and glare — glossy film under bright lights can confuse cameras; matte finishes scan more reliably.

Share a card with menu or review codes

Many cafes put menu, Wi‑Fi, and Google review codes on one tent. That works when each square has room and a short label (“Wi‑Fi”, “Menu”, “Review”). Do not mash three codes into one microscopic stamp.

  • Layout ideas: cafe table tent menu, Wi‑Fi, and review QR.
  • Menu permanence: restaurant menu QR that never expires.
  • Review without a monthly fee: free Google review QR (no monthly fee); also static Google review QR.

If only the Wi‑Fi password changes, swap that panel and leave menu/review panels alone—another reason to keep separate codes instead of one mega‑payload.

Password rotation without chaos

Static guest Wi‑Fi QRs encode today’s password. When you rotate the router password (seasonal wipe, security incident, staff turnover), old stickers keep advertising the old secret.

  1. Change the router guest password.
  2. Regenerate the QR with the new credentials.
  3. Reprint or resticker every public copy.
  4. Archive the new SVG with the change date.

Full walkthrough: Wi‑Fi QR not working after password change. Prefer static when rotations are rare; consider dynamic only when you must revoke without reprinting—and you accept vendor lock‑in and trial cliffs (QR expired after free trial).

What this is not

A guest Wi‑Fi QR does not create captive‑portal login pages, does not enforce bandwidth caps, and does not replace router security settings. It also will not fix a mistyped SSID you baked into the first design. Re‑test after any router “quick setup” wizard that silently renames the network.

FAQ

What information goes into a guest Wi‑Fi QR code?

SSID, security type, password, and optionally a hidden‑network flag. Phones offer to join from that payload.

Is a guest Wi‑Fi QR better than telling customers the password?

Usually yes in noisy cafes: faster, fewer typos, less staff interruption.

What print size should I use for a table Wi‑Fi QR?

Size for the real scan distance and keep contrast high. See print size by scan distance.

What happens when we change the guest Wi‑Fi password?

Regenerate, reprint, archive. Static images do not auto‑update. Guide: password‑change fix.

Can I make a guest Wi‑Fi QR for free without signup?

Yes—use the Wi‑Fi QR code generator, download PNG/SVG, and print. No account.
