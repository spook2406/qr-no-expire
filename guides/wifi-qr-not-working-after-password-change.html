Wi‑Fi QR code not working after password change

Guests scan the table tent, sticker, or counter card—and the phone fails to join Wi‑Fi, or joins nothing useful. Yesterday it worked. Today you rotated the router password (or renamed the network). The ink still looks fine. The square still “scans.” The credentials inside it are simply out of date.

This guide explains why that happens with static Wi‑Fi QR codes, how to fix it in a few minutes, and how to avoid a stack of dead prints next time. When you are ready to recreate the code, use the free browser tool: Wi‑Fi QR code generator (no signup; payload stays on your device).

Why the old print fails

A Wi‑Fi QR is not a live tunnel to your router admin panel. In the usual static form it is a small text payload (the well-known WIFI:... format) drawn into the image. That payload typically includes:

  • SSID — the network name
  • Password / pre-shared key
  • Security type — e.g. WPA/WPA2
  • Optional flags such as hidden network

When someone scans it, the phone reads those values and tries to join. If you changed the password in the router, every previously printed PNG, SVG, or laminated card still encodes the old password. The QR did not “expire” in the vendor-trial sense; it became stale.

That is different from a dynamic short-link QR that opens a URL you can edit on a dashboard. Dynamic codes can sometimes be pointed at new instructions without reprinting—but they introduce vendor lock-in and the familiar “free trial ended” failure mode. For a comparison, see static vs dynamic QR codes and how to tell which you have.

Confirm it is really a password/SSID mismatch

  1. Scan with a second phone. If every device fails after the router change, it is almost certainly credentials—not one buggy camera.
  2. Join the network manually with the new password. If manual join works but the QR fails, the print is stale.
  3. Check whether you renamed the SSID as well as the password. Either field invalidates the old payload.
  4. Rule out print damage if the camera cannot detect a code at all (smudge, low contrast, tiny quiet zone). See print size by scan distance and the general triage in why did my QR code stop working.

Fix path: regenerate, then reprint

  1. Generate a new static Wi‑Fi QR with the current SSID, security type, and password using the free Wi‑Fi QR generator.
  2. Test before you print a hundred copies. Scan on iPhone and Android; confirm the join prompt and a successful connection.
  3. Download PNG for quick prints and SVG for sharp reprints at larger sizes. Keep the SVG (or a note of the exact payload fields) in a shared drive so the next password rotation is boring, not forensic.
  4. Replace physical touches: table tents, reception stickers, menu backs, Airbnb binders, meeting-room cards. One stale card will keep generating support questions.
  5. Destroy or mark obsolete stock so staff do not recycle the old design “because we still have fifty.”

Prevention for cafes, shops, and guest networks

  • Prefer static for guest Wi‑Fi you control when password changes are rare (seasonal wipe, security incident). Reprinting a tent card is cheaper than remembering another SaaS login.
  • Document the rotation ritual: who changes the router → who regenerates the QR → who replaces tents. Put the SVG path in the same checklist.
  • Combine carefully on one tent. Menu + Wi‑Fi + review codes are popular; if only the Wi‑Fi password changes, you can swap that panel without reprinting unrelated codes. Layout ideas: cafe table tent QR codes. Cafe and restaurant setup: guest Wi‑Fi QR for a cafe or restaurant.
  • Use dynamic only when remote revoke matters (shared housing with frequent lockouts, campaigns you must kill instantly). Budget for the subscription and monitor trial cliffs—see QR code expired after free trial.
  • Do not laminate a password you expect to rotate weekly unless you enjoy scrap work. High-churn networks need either dynamic redirects or cheap paper reprints.

What this is not

A static Wi‑Fi QR will not push password updates to phones that already joined, will not bypass router MAC filters, and will not fix a mis-typed SSID you baked into the first design. It also will not survive a security-type change (for example moving from WPA2-Personal assumptions to a different scheme) without a fresh payload. Re-test after any router “quick setup” wizard that silently renames the network.

FAQ

Why did my Wi‑Fi QR stop working after I changed the password?

Because the old image still encodes the previous password. Static codes do not phone home to your router for updates.

Can I update a printed Wi‑Fi QR remotely?

Only if it was a dynamic / redirect product you still control. Pure static Wi‑Fi payloads need regenerate + reprint.

Do I need a new QR if I only changed the SSID?

Yes. SSID and password both live in the payload.

Should guest Wi‑Fi use static or dynamic QR codes?

Static for simple guest access you can reprint; dynamic when you need remote edits and accept vendor risk. Start with how to tell static from dynamic.
