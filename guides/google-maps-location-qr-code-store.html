Google Maps location QR codes for your store

A window decal, table tent, or event poster can carry a QR that opens your place in a maps app—so a guest does not have to type the address. The print-safe version is static: the location is written into the image as a Google Maps URL (the default) or, optionally, a compact geo: URI. There is no signup to keep the square working, and no short link in the middle that dies after a trial.

Scanning usually opens a maps app or a browser. The person confirms navigation; the scan does not auto-start turn-by-turn directions. qrstatic.app is an independent static QR tool. It is not affiliated with Google, Apple, or any maps provider. Those names belong to their owners. The page only formats a URL or geo: payload those apps already know how to open.

Use this for lawful sharing: your storefront, a public event, or another place you may disclose. Do not encode a private or sensitive location without consent.

Maps URL vs geo: — which should you print?

Default: a Google Maps URL. It is the most portable choice for mixed-device print (table tents, posters, invitations), including many iOS Camera scans. A typical pattern looks like https://maps.google.com/?q=40.7128,-74.0060. Maps URL mode can use a place query alone, coordinates alone, or both. If you use a query alone, proof-scan and confirm the pin is your store—common business names can resolve to the wrong place.

Optional: a geo:lat,lon URI. This payload is shorter, so the QR can be less dense. The name is not encoded in geo: mode—you need coordinates only. On Android, geo: can hand off to a maps app especially cleanly. On iOS, Camera and link handling for geo: can differ, so prefer the Maps URL when you cannot control which phones will scan the print.

Neither format starts driving by itself. The guest still reviews the pin or search result and chooses directions.

A static payload has no generator trial clock: the URL or geo: string lives in the image, and coordinates or addresses stay in your browser (nothing is uploaded to create the code; no short link is minted). Maps apps still control how those links open after an OS or app update—retest if reports start to look like “the QR broke.” Invalid coordinates show a clear error; they are not silently turned into a QR.

If you later move storefronts, the old print still points at the old place. Generate a new image and replace the sign.

How to make a store or event location QR

  1. Choose the payload for the devices you expect. For a shop window, table tent, or invitation that anyone might scan, start with a Maps URL. Use geo: only when you specifically want the compact coordinates URI and have tested the target phones. In Maps URL mode you can enter a query, coordinates, or both; geo: needs coordinates.
  2. Generate the static image in the browser. Soft CTA: use the location / maps QR code generator—no signup; coordinates and addresses stay on your device. Download SVG for print and PNG for screens and proofs.
  3. Label the square, size it, and proof-scan. Write “Find us,” “Directions,” or the store name so it is not mistaken for Wi‑Fi or a menu. Start around 2–2.5 cm on a handheld card or invitation, and 3–4 cm on a table tent or door sign, with a white quiet zone. Confirm that a phone opens the right place and that navigation starts only after the guest confirms. For distance-based sizes, see QR code print size by scan distance.

Do not put a free shortener in front of the Maps URL “to track scans” unless you are deliberately paying for a redirect you trust. That reintroduces a middleman that can fail independently of the place.

Storefronts, table tents, and one-night events

A location QR works well as one labeled square next to the other jobs a café or shop already prints:

  • Menu, Wi‑Fi, and review codes on the same tent—see one café table tent, three static QR codes. Add a map code only if guests actually need directions from the table (a food-hall stall or a hard-to-spot entrance). An unlabeled fourth square just adds clutter.
  • Guest internet should stay a static Wi‑Fi payload on a guest SSID, not a map pin. Details: guest Wi‑Fi QR codes for cafés and restaurants.
  • A window decal or sidewalk sign can carry the location QR alone: clear label, static Maps URL, proof-scanned in daylight and at night if the sign is lit.

If the place is tied to a time (a popup, a tasting, a one-night event), you can also print a separate calendar event QR so guests save the slot. Keep each square labeled; the location code is still the map, not the calendar.

FAQ

Should I use a Google Maps URL or a geo: QR?

Prefer a Maps URL for most print jobs—it is the better cross-device default, including many iOS Camera scans. Use geo:lat,lon when you want a shorter coordinates-only payload and have tested the devices you care about. The place name is not stored in geo: mode.

Does scanning start turn-by-turn navigation automatically?

Usually no. The device opens a maps app or a browser so the guest can view the place. They confirm directions; the QR does not start navigation by itself.

Does a store location QR expire?

A static payload does not expire because of a generator trial—the Maps URL or geo: string lives in the image. If you move, reprint. Maps apps still control how those links open. If the square opens a third-party “expired / upgrade” page, someone likely encoded a dynamic short link instead of the location payload.

Is this an official Google Maps or Apple Maps tool?

No. qrstatic.app is not affiliated with Google, Apple, or any maps provider. It only formats a Maps URL or geo: payload.

Are my coordinates or address uploaded?

No. Generation runs in your browser. Coordinates and addresses are not uploaded to create the image, and the site does not mint a short link that can die after a trial.

What if I enter invalid coordinates?

The generator shows a clear error and does not silently build a QR. Whitespace is trimmed; fix the latitude and longitude (or switch to a Maps URL query) and try again.

Can I put a map QR on the same table tent as menu and Wi‑Fi codes?

Yes, if each square is clearly labeled and large enough to scan. Treat the map as an optional extra when guests need directions—not a replacement for guest Wi‑Fi or a menu URL. See the café table tent guide.
