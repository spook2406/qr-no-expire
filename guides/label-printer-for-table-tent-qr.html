Measure the code before you price a printer

The print-size guide starts a table tent, menu insert, or counter card at about 3–4 cm wide for a scan from 30–50 cm, and a handheld card at about 2–2.5 cm. Those numbers are the code square only. Add the quiet zone, the white margin the camera needs, and any words that must sit on the same piece of media.

The table-tent guide puts three separate squares on one tent (menu, guest Wi-Fi, review), each with its own quiet zone. If that is the job, the thing you are buying has to hold that layout. A faster printer does not shrink the square.

Build the files first, then shop for media. Menu and review codes are static URLs from the homepage generator. The guest network code comes from the Wi-Fi QR generator. Keep SVG as the master file so you are not enlarging a tiny PNG.

When you do not need a new printer

  • You reprint a few times a year. A seasonal menu change or a rare password rotation does not require a dedicated label printer. Use the laser or inkjet you already have, or a print shop, and keep the SVG.
  • The job is a folded tent. A tent has to stand. Copy paper flops. Check the maximum paper weight in your printer’s manual, and use cardstock the tray can feed. If the tray refuses thick stock, a shop is the purchase, not a 2-inch label printer.
  • The layout is three codes. That face is wider than a 62 mm roll. Skip the desktop label-printer class below.

Do not buy hardware to make a QR “work better.” If a proof fails, the print-size guide’s fixes are size, quiet zone, contrast, and matte stock. A new printer does not change a payload, and it does not revive a redirect that expired after a trial.

Sheet labels, if you already have a printer

Match the label’s short side to the code plus quiet zone. A common address label, Avery 5160, is 1 inch by 2-5/8 inch. One inch is 25 mm, which is shorter than a 3 cm table code and tight even for a 2 cm handheld code once the quiet zone is included. Do not use that sheet for a tent.

A narrow label printer is only for a small sticker

Buy this class when you reprint one small sticker often, such as a guest Wi-Fi card after password rotations, and the whole sticker including the quiet zone fits in the printable width. It is the wrong class for the three-code tent.

One model in that class is the Brother QL-800. Brother’s specifications list:

  • Direct thermal, DK rolls, no ink cartridge.
  • Maximum label width 62 mm (about 2.4 in) and maximum print width 58 mm (about 2.3 in). The code has to fit in the print width, not only on the roll.
  • USB 2.0. There is no Wi-Fi on this model. You print from the computer it is plugged into.
  • 300 × 300 dpi in standard mode, and 300 × 600 dpi in high-resolution mode.
  • Black and red together only on a two-color DK roll. The QR itself should stay dark on a light ground. A red module is not a feature to shop for.

A 2–2.5 cm handheld code plus a quiet zone can fit inside 58 mm. A 3–4 cm table code plus its quiet zone uses most or all of that width, with no room beside it for “Menu” and two more squares. Treat the QL-800 as a small-sticker printer.

Direct thermal stock darkens with heat, strong sun, and some solvents. A window in afternoon sun is a poor place for it. Tape a sample where the card will live before you buy a case of rolls. Recheck Brother’s current spec page before you order; widths and bundle contents change by region.

Label tape is the wrong width for a tent

Laminated label tape, the P-touch style cassette, is commonly sold around 6 mm, 9 mm, 12 mm, 18 mm, and 24 mm, and some cassettes are 36 mm. The print-size guide starts a table-tent code at 3–4 cm before the quiet zone. Even a 36 mm cassette is narrower than a 4 cm square, and a 3 cm square plus a quiet zone does not fit on it either.

Use that tape for a shelf edge, a cable, or a jar, if the text is the point. Do not buy it for the tent QR. There is no product slot here, because the decision for this job is not to add a tape printer.

A short decision

  1. Size the code with the print-size guide, including the quiet zone.
  2. If the artwork is the three-code tent in the table-tent guide, print it on cardstock or at a shop. Skip a 62 mm label printer and skip label tape.
  3. If the artwork is one small sticker you reprint often, price either a direct-thermal printer in the QL-800 class or a 2 by 4 inch / 3-1/3 by 4 inch sheet that matches the printer you already own.
  4. Proof one print with an iPhone and an Android under the room lights before you buy a bulk pack.
  5. Generate the payload on the static generator or the Wi-Fi generator. The printer does not create the QR, and it does not update a card after you change a password. Reprint steps for a guest network are in the password-change guide.

FAQ

Do I need a label printer to print a table-tent QR?

No. A folded tent with a 3–4 cm code is usually cardstock or a print-shop job on a printer you already have. A desktop label printer in the 62 mm class is for a small sticker, not for that tent.

Can label tape hold a table-tent QR code?

Not at the starting size in the print-size guide. Common laminated tapes are about 6–24 mm wide, and some cassettes are 36 mm. A table-tent code starts around 3–4 cm before the quiet zone, so the tape is narrower than the square.

Does a higher print resolution fix a code that is too small?

No. A Brother QL-800 prints at 300 by 300 dpi in standard mode and 300 by 600 dpi in high-resolution mode. That is enough when the square already matches the scan distance. Resolution does not replace physical size, quiet zone, or contrast.

Is a Brother QL-800 a table-tent printer?

No. Brother lists a maximum label width of 62 mm and a maximum print width of 58 mm, USB 2.0, and direct thermal DK rolls. Use that class for a small sticker whose quiet zone fits inside 58 mm. It does not produce a folded three-code tent.

Will a new printer make a static QR permanent?

No. A static QR stays scannable because the payload is in the image, not because of the printer. A redirect on a free trial can still die. The printer only puts ink or heat on the media you chose. See QR codes that never expire and static vs dynamic.
