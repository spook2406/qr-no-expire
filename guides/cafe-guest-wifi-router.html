The QR does not replace a router setting

A guest Wi-Fi QR stores the network name, the security type, and the password inside the image. The Wi-Fi QR generator writes that WIFI: string in the browser. Phones that understand it offer to join. The square does not create a second network, and it does not move the point-of-sale system off the staff SSID.

If guests and the register share one name, a sharper print still joins that shared network. Fix the router, or decide you do not want a separate guest network, before you print a stack of tents. Layout for the card is in the table-tent guide, and the starting size is in the print-size guide (about 3–4 cm for a seated scan).

Replacing the router does not edit cards already on the tables. When the guest password changes, follow the password-change guide: change the router, generate a new image, reprint.

Keep the router you have when these are already true

  • A guest SSID exists and it is not the staff or POS name.
  • Guests cannot reach the local network. The control may be labeled “access intranet,” “access your local network,” “AP isolation,” or “client isolation.” Test with a phone that is not your admin device: it should join the guest name and fail to open the register, a staff printer, or a shared drive. A successful join is not a safety certificate. It tells you the checkbox did what the screen said.
  • The dining room has signal on that SSID, including the back tables, not only the counter where the router sits.
  • Security matches the generator. For almost every passworded guest network, choose WPA/WPA2 in the tool, which stores T:WPA. A WPA2 passphrase is 8 to 63 characters. If the router is set to WPA3 only, join from an older phone before you print a stack. Use WEP only to match a router you have not replaced. The guest Wi-Fi guide covers the same security choices.
  • The SSID is broadcast. Leave hidden off unless the router truly hides the name. Hiding the name is not a substitute for a separate guest network.

If those points are true, stop. Do not buy a router to make the QR “stronger.”

Buy a router when one of these is missing

  • The admin page has one SSID, and the POS is on it.
  • There is no guest-network control and no way to stop wireless clients from reaching LAN devices.
  • The ISP gateway cannot isolate clients, and you cannot add a guest SSID in front of it.
  • You need a passphrase you can rotate and type into the generator, without a splash page the QR cannot finish. See the next section before you shop for a portal.

Log into the admin page you already use. This guide does not list default passwords. If you cannot sign in, reset and recovery belong to the vendor’s own instructions for equipment you own.

A captive portal is a different purchase

A WIFI: code joins the network. It does not tap “accept,” enter a voucher, or pass an email gate. If you require a splash page, guests still get that page after the phone joins. Do not buy portal hardware because you expect the QR to skip it. This page does not explain how to remove, bypass, or hide a portal, a paywall, or a sign-in wall.

For a small cafe that only wants “join guest Wi-Fi,” a separate SSID plus the printed code is the whole job. A portal adds a step the QR cannot complete.

What not to buy for this job

  • A repeater that clones the staff SSID. It extends the network you were trying to keep off the tables. If you add coverage, the extra radio has to offer the guest name, and you should test a back table before you print.
  • A router chosen for a gaming speed number. Guest Wi-Fi here is isolation plus enough signal to join. A higher AX figure does not add a guest SSID that the firmware lacks.
  • A travel router that only repeats one upstream network and has no guest network of its own. Read the manual for a guest SSID and a local-network block before you treat it as the cafe router.

One consumer example, not a ranking

The TP-Link Archer AX55 is one dual-band consumer router in the class above. TP-Link’s spec sheet lists one 2.4 GHz guest network and one 5 GHz guest network. The AX55 user guide puts the feature under Advanced, Wireless, Guest Network, and the permission checkboxes are “Allow guests to see each other” and “Allow guests to access your local network.” For a cafe guest network, leave both unchecked, set a WPA2 or mixed-mode passphrase of 8 to 63 characters, and do not hide the SSID. Then test from a phone that is not signed in as the admin: join, and try to reach a staff device.

The two bands can be two names. A WIFI: QR stores one of them. Print the name you want phones to join. If you need older phones on 2.4 GHz, that is the name to encode, unless you have confirmed both radios can share one SSID and one password.

The AX3000 speed line on the box is not the reason to pick this model. Confirm the guest screen in the manual for the hardware revision you are about to buy. Firmware layouts move, and a later revision can rename a menu. This is an example of the spec class, not a placement on a list.

A short decision

  1. Open the router you have and look for a guest network.
  2. If it is there, turn it on, turn off access to your local network, match WPA2 in the Wi-Fi generator, proof-scan, and stop shopping.
  3. If it is not there, replace the router with one that has a separate guest SSID and those isolation checkboxes. The Archer AX55 is one model in that class. The slot above is where a product link would go after approval.
  4. If the counter joins and the back tables do not, move the router or add coverage on the guest name. Test that spot before you print more tents.
  5. Size the card with the print-size guide. If the printed piece is the purchase you are unsure about, use the label printer and sheet guide. The router does not choose the paper.

FAQ

Will a new router update the Wi-Fi QR codes already on the tables?

No. A static WIFI: image keeps the SSID, security type, and password you encoded. Replacing the router does not edit those cards. If the guest name or password changes, generate a new code and reprint.

Can a guest Wi-Fi QR skip a splash page or voucher?

No. The QR joins the network named in the image. It does not complete a captive portal, voucher, or email gate. If you require that page, guests still see it after the join. This guide does not explain how to get around one.

Should the printed QR use the POS or staff password?

No. Put a separate guest SSID on the card. Anyone who can photograph the tent can read the password, because it is inside the WIFI: payload. Staff and payment devices stay on the other network so a guest-password change does not knock them offline.

Do I need Wi-Fi 6 for a cafe guest network?

Not for this job. The purchase that matters is a separate guest SSID, a control that keeps guests off the local network, and coverage at the tables. A higher speed number on the box does not decide it.

What if 2.4 GHz and 5 GHz use different guest names?

A WIFI: QR stores one SSID. Print the name you want phones to join. If the two bands cannot share one name, leave a second code off the card or print a second labeled square. Do not buy a second router only to rename a band.
