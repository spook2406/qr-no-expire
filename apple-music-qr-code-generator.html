Which links are accepted

The host must be music.apple.com. geo.music.apple.com and www.music.apple.com are the same public catalog and are rewritten to music.apple.com. http becomes https. The hash is dropped. Affiliate and tracking parameters at, ct, pt, ls, app, uo, itsct, itscg, utm*, fbclid, and gclid are removed. This page does not add any affiliate or campaign parameter of its own. The storefront stays as pasted, so a gb link stays gb and a jp link stays jp. The public path stays:

  • https://music.apple.com/us/song/track-name/1234567890 — a public song
  • https://music.apple.com/us/album/album-name/1524801260 — a public album
  • https://music.apple.com/us/album/1524801260 — the same album with the slug omitted
  • https://music.apple.com/us/album/album-name/1524801260?i=1650237741 — an album link that opens one song
  • https://music.apple.com/us/playlist/playlist-name/pl.xxxxxxxx — a public playlist

You may omit https://. These examples are shapes, not real pages. A public playlist id starts with pl. and its letter case is kept.

What is rejected

Empty input is an error. An artist page (/artist/) is rejected. Radio and Station are rejected. A music-video link is rejected. /library/, Listen Now, Browse, Account, Settings, and Subscribe are rejected, because those surfaces are not a public song, album, or playlist that opens without signing in. Redeem codes, trials, offers, and gift codes are rejected. Apple ID login, 2FA, authenticator, keychain, and SharePlay links are rejected. Do not use this page for Apple ID login, redeem, or trial.

itunes.apple.com is rejected. An apple.co short link is rejected, because this page does not follow network redirects. music.youtube.com is rejected. Other websites are rejected. A short link or redirect on qrstatic.app is rejected, and the QR never contains qrstatic.app. None of those are silently encoded.

A Spotify link is not encoded here. Use the live Spotify tool: https://qrstatic.app/spotify-qr-code-generator.html. An App Store link on apps.apple.com is not encoded here. Use the live App Store and Google Play tool: https://qrstatic.app/app-store-google-play-qr-code-generator.html.

A scan does not open a private library, and it does not bypass a region limit or a subscription wall. If the page asks for an Apple ID, Apple still enforces that. This tool does not try to get around it. Use only links that open without signing in.

Songs, albums, and playlists

This page only does public songs, albums, and playlists. A song URL opens that song. An album URL opens the album, and an i= parameter on that album URL is kept so the scan can open one song inside it. A playlist URL opens that public playlist. Artist pages, radio, and a personal library are out of scope and are not encoded. Paste the public page you want the scan to open.

If the playlist changes, reprint

If a playlist is made private, deleted, or the link changes, a printed static code will stop working and must be remade from the current public link. The image stores the URL that was encoded. We cannot edit a code that is already on paper. Generate a new PNG or SVG from the public link that opens today, and replace the print.
