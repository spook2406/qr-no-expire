Which links are accepted

The host, after www is removed, must be whatsapp.com, and the path must be /channel/ plus the public code. http becomes https. The hash is dropped. Tracking parameters utm*, fbclid, gclid, and the other share trackers are removed. The public path stays:

  • https://whatsapp.com/channel/… — a public channel follow link
  • https://www.whatsapp.com/channel/… — the same link, rewritten without www

You may omit https://. These examples are shapes, not real channels. The code in the path is kept as copied, including its letter case.
