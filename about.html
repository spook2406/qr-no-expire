About qrstatic

Maintained by Ethen · qrstatic.app

qrstatic (qrstatic.app) is a free set of static QR code generators for people who need a square they can download and print. You open a page, type the payload you actually want scanned—a URL, a guest Wi‑Fi password, a phone number, a review link—and the browser draws a PNG or SVG. There is no account. The site does not mint a short link, and it does not run a redirect that the printed code has to call later.

What “static” means here

A static QR code stores its contents in the image. The dark and light modules are a machine-readable copy of a text string. A phone camera recovers that string and acts on it: open a web page, join a Wi‑Fi network, start an email draft, save a contact, or open a map. Nothing on qrstatic.app has to stay online for that scan to succeed. If this website were unreachable, a PNG you had already downloaded would still scan, because the data was never stored on a server this site controls.

Codes that “expire” are usually a different product wearing the same square. The image encodes a short URL on a domain the generator operates. Their server looks up that short URL and forwards the phone to your real destination. When a free trial ends, a subscription lapses, or the vendor shuts the domain down, the lookup fails. The ink is intact; the pointer is dead. That failure mode is why a table tent can stop opening a menu or a review form even though the print still looks fine.

qrstatic.app does not offer that lookup. There is no dashboard where a destination can be swapped after printing, and there is no subscription that keeps an image “on.” The file you download is the whole product. Practical comparisons live in the guides, especially static vs dynamic QR codes and how to tell which kind you already printed.

How a code is made

Rendering uses the MIT-licensed soldair/node-qrcode library, bundled for the browser. Each page builds a payload in JavaScript on your device, then asks that library to draw it on a canvas. You can download PNG for a screen or SVG for print. Size, error correction (L, M, Q, or H), quiet zone, and colors change the drawing. They do not insert a server between the scan and the data.

The pages are a static site. There is no generation API. Clicking Generate does not submit the form to a backend. The same library call is what the homepage generator and the dedicated tools use.

Privacy of the payload

URLs, Wi‑Fi passwords, phone numbers, review links, and TOTP secrets are handled in the browser while the image is drawn. There is no account database of codes you have made. This site cannot open a history and tell you what you encoded, because that text was never received. The Privacy Policy describes this in operational detail, including what GitHub Pages logs and what Google Analytics does on a page view.

Two boundaries are easy to miss. First, a file you later email to a printer, or a photo you post, is then outside this site—anyone who can see the image can scan it. Second, the site loads Google Analytics and may load Google AdSense. The generator does not send the payload to a qrstatic.app server and does not attach it to an event we control. Those third-party scripts still run in the browser on the same page, so do not type a secret you would not want present while they are loaded. The Privacy Policy states this more carefully. Advertising does not change how the image is drawn.

The tools

Each tool builds one kind of string, then uses the same client-side renderer. The string is what a camera recovers:

  • Homepage generator — a URL (an omitted scheme is prefixed with https://), plain text, a WIFI: connection string, a mailto: draft, or a tel: link. Wi‑Fi fields escape backslash, semicolon, comma, and double quote so the payload stays valid.
  • Wi‑Fi — the same WIFI:T:…;S:…;P:…;; string, with notes for guest networks and reprinting after a password change.
  • vCard — a vCard 3.0 block (BEGIN:VCARD) a phone can offer to save.
  • Calendar — a minimal VCALENDAR / VEVENT a calendar app can import.
  • Google Review — a Place ID or an official Google review URL. A bare Place ID becomes https://search.google.com/local/writereview?placeid=…. Non-Google URLs are rejected. This is not a Google product.
  • SMS — an SMSTO: payload that opens a text draft. The person still taps Send.
  • WhatsApp — a https://wa.me/ click-to-chat URL (digits only, optional prefilled text). Not a WhatsApp Web login QR, and not affiliated with Meta.
  • Email and phone — the same mailto: and tel: payloads as the homepage, on their own pages.
  • Location — a Google Maps URL by default, or a geo:latitude,longitude URI if you choose that mode. A place name is not written into a geo: payload.
  • TOTP — an otpauth:// URI for an authenticator app. The secret is inside the image. Treat the file like a password.
  • Spotify, Telegram, Discord, and Zoom — the public share or join URL you paste, lightly normalized. Tracking parameters are stripped. A Zoom pwd query is kept. These pages are not official tools of those companies.
  • Google Meet — a meet.google.com/xxx-xxxx-xxx link or a bare meeting code, rewritten to the canonical HTTPS join URL. Not a Google product. A one-time meeting can stop accepting joins after it ends; a recurring room code can stay on a poster. Encoding the URL does not bypass a waiting room.
  • Microsoft Teams — the full teams.microsoft.com/l/meetup-join/… or teams.live.com URL. The join token is kept. An Outlook Safe Links wrapper is unwrapped in the browser when the real Teams URL is inside it. Not a Microsoft product. Lobby and tenant policy still apply, and a long join URL makes a denser code, so print it larger.

Limitations, stated plainly

Static means one specific thing: no vendor subscription can switch the image off. It does not mean the destination you pointed at will last forever, and it does not mean the code can be edited in place.

  • No edit after print. A new Wi‑Fi password, a moved URL, a new phone number, or a revoked invite needs a new image. Reprinting is the update. There is also no remote kill switch.
  • No scan analytics. These tools do not count scans. If you need counts, they have to live on a website you control, not inside the QR.
  • Dynamic products solve a different job. One printed square whose destination you can change later is a real need. A static file is the wrong tool for that job.
  • Other companies still control their own links. A Discord invite or a Telegram invite can expire on that service even though this image has no trial clock. A Zoom, Google Meet, or Teams meeting can end or be revoked. Google can change a review URL format. The QR only preserves the string you encoded.
  • Phones disagree. iOS Camera handles many Wi‑Fi codes and Maps URLs reliably. geo: and some SMSTO forms vary by device. Test on the phones your guests actually carry before you print a stack. The print-size guide covers quiet zone and contrast.
  • “Free” is about the file, not a promise that this website lasts forever. There is no signup and no fee to generate or download. The file you keep is what does not depend on this site staying up.
  • No affiliation. qrstatic.app is not affiliated with Google, Microsoft, Telegram, Discord, Spotify, Zoom, Meta, WhatsApp, or any phone carrier. Those names describe the payload format only.
  • Do not encode a secret you cannot afford to leak. A Wi‑Fi QR is a printed password. A TOTP QR is a printed authenticator secret. A Zoom link that includes ?pwd= is a printed meeting password.

You are responsible for having the right to encode and distribute what you put in the image. The Terms of Use say that directly, including the rule against using the tools for phishing or other unlawful payloads.
