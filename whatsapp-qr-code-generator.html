Click-to-chat, not login

WhatsApp Web shows a login QR that ties a phone session to a browser. This page does the opposite: it encodes a public click-to-chat link (https://wa.me/…) so a customer can start a conversation with your business number. api.whatsapp.com/send is functionally similar for many clients; this tool builds wa.me only. It does not create a session, pair a device, or talk to WhatsApp’s servers.

What the page writes into the image

The generator keeps digits and drops spaces, parentheses, dashes, and a leading plus. If you fill the separate country-code field, those digits are placed in front and a leading zero on the national number is removed. The result must be 8 to 15 digits, which is the length check used for an E.164-style number. The QR then contains https://wa.me/ plus those digits. An optional message is added as a text query, percent-encoded. A message longer than 500 characters still encodes, with a warning that some WhatsApp clients truncate it.

That URL is rendered in your browser with the same client-side library as the other tools. Nothing is uploaded, and there is no short link on a qrstatic.app domain. A scan opens WhatsApp (app or web) on a chat with that number. The prefilled text, if any, is a draft—the person still sends it. If you change the business number, the old print still points at the old number; make a new image and replace the card.

A counter card or a table tent is the intended use: a number you are allowed to publish, for people who choose to write to you. Do not print a login QR from WhatsApp Web and do not use this page to assemble unsolicited blasts.

FAQ

Is this a WhatsApp Web login QR?

No. The payload is a public https://wa.me/<digits> click-to-chat URL. Login and device-pairing codes are a different mechanism, and this page does not produce them.

Is QRStatic affiliated with Meta or WhatsApp?

No. This is an independent static QR tool. WhatsApp and Meta names belong to their owners. The page only formats a link those apps already know how to open.

Does the WhatsApp QR expire?

The image does not depend on a generator trial or a redirect we host. It keeps the wa.me URL you created. WhatsApp can still change how that URL opens, and a number you no longer control will not start a useful chat. Retest after major app updates, and reprint if the number changes.

Can I use this for spam?

No. Use it for a number people are invited to message—your shop, your own phone—not for unsolicited lists. Scanning opens a draft; it does not send a message by itself.

Why was my number rejected?

The digit string was shorter than 8 or longer than 15 after punctuation was removed, or the country code was missing. wa.me needs the country calling code in the digits (for example 15551234567), not a local number alone.
