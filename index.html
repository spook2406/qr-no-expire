Static QR codes and codes that expire

A static QR code is a picture of the data. The modules encode a string—your URL, a WIFI: network line, a mailto:, a tel: number—and the camera reads that string directly. This site never stores the string and never issues a short link that has to be resolved later. The PNG or SVG you download is the whole code. There is no account that can turn it off.

An expiring or “dynamic” code looks the same on paper and behaves differently. The square usually contains a short URL on the generator’s domain. Their server looks up that URL and redirects the phone. The lookup is the product: you can change the destination without reprinting, and the vendor can count scans. It also means the print depends on that server. When a trial ends, a plan lapses, or the company shuts the redirect down, scans fail even though the ink is fine. The longer comparison is static vs dynamic QR codes. If you already have a print and are not sure which kind it is, use how to tell a static code from a dynamic one.

Static is the wrong choice when you need to change the destination after the piece is printed, or when you need the QR vendor’s scan counts. It is the right choice when the payload itself should be what gets scanned, and you would rather reprint than rent a redirect.

Who the tools are for

The everyday user is someone printing a small run, not running a QR campaign. A cafe or restaurant puts the guest network on a table tent so staff stop reading the password aloud. A small shop puts a review link on the counter and does not want a monthly fee standing between the card and Google. A wedding, a clinic front desk, or a one-page menu can point at a URL the owner actually controls—their own site, a map pin, a phone number—rather than a short link that belongs to a trial account.

The tools assume you will test one phone, then print. They do not track guests, edit a code that is already on the table, or host your menu. If the Wi‑Fi password changes, the old sticker still contains the old password; you generate again and replace the card. That workflow is written up for cafes in the guest Wi‑Fi guide and for password rotations in the reprint guide, both linked below.

How to use a generator

  1. Open the tool that matches the payload. Do not paste a temporary short link from another QR service into the URL field if you want the print to outlive that service. Paste the real destination.
  2. Generate, then scan the preview with your own phone before you download. Confirm the Wi‑Fi name, the review form, or the map pin—not just that “a code appeared.”
  3. Download PNG for a screen, or SVG when a printer will scale the mark. Leave the quiet zone. Print one sample before a stack of tents or stickers.

Guest Wi‑Fi. Use the Wi‑Fi generator. It writes a standard WIFI: string (network name, security, password) into the image. For a cafe or restaurant layout, follow how to make a guest Wi‑Fi QR for a cafe or restaurant. When the password changes, the old print cannot be updated in place—see Wi‑Fi QR not working after a password change.

Google reviews. Use the Google review generator. Paste the Place ID or the official review link from your Business Profile. A Place ID is turned into Google’s write-review URL; other websites are rejected. qrstatic.app is not affiliated with Google. The walkthrough that skips subscription short links is a free Google review QR with no monthly fee.

A place on a map. The location generator encodes either a Google Maps URL or a geo:latitude,longitude URI. Maps URLs are the better default for mixed iPhone and Android tables; geo: is shorter and omits the place name. Pair a map code with the print guides already on the site: one cafe table tent with menu, Wi‑Fi, and reviews, a menu QR that points at a page you host, and print size by scan distance.

Tools

Same renderer on every page: the payload is built in your browser and the image is yours to keep. Pick the page that matches the string you need.

  • Homepage generator — URL, plain text, Wi‑Fi, email, or phone, with size and error correction.
  • Wi‑Fi QR — guest networks and reprinting after a password change.
  • Google review QR — Place ID or an official review link. Not a Google product.
  • Location / Maps QR — Maps URL or geo: coordinates.
  • vCard — a contact card. Calendar — one event. TOTP — an authenticator enrollment secret; do not publish that image.
  • SMS, WhatsApp click-to-chat, email, and phone — a draft or a call the person still confirms. WhatsApp here is not a login QR.
  • Spotify, Telegram, Discord, Zoom, Google Meet, and Microsoft Teams — the public link you paste. Meet accepts a meet.google.com link or a bare meeting code. Teams needs the full meetup-join URL and can unwrap an Outlook Safe Link. Meetings can still end on those services, and a posted join link does not bypass a waiting room, lobby, or org policy.
