Contact

Maintained by Ethen · qrstatic.app

qrstatic.app is a free, browser-side toolkit for static QR codes. You type a payload, the page draws a PNG or SVG, and you keep the file. There is no account, and the site does not host a redirect behind the image. The About page explains that design, the tool list, and the limits. This page is how to reach the person who maintains it.

Email

Write to smithk@gmail.com. That mailbox is read by Ethen, who maintains the qrstatic.app product. It is the only contact address. There is no phone number, no postal address, and no live chat—those are not withheld; they do not exist. Please do not send Wi‑Fi passwords, TOTP secrets, or other credentials you would not want sitting in an email thread. Describe the field (for example “guest SSID with an apostrophe”) instead of pasting the secret.

Useful messages include:

  • What you were trying to do (URL, Wi‑Fi, vCard, calendar, Google review, location, or a guide page)
  • Your browser and device (for example Chrome on Android, Safari on iPhone)
  • The exact error text, or a screenshot of the page—not a screenshot of a password
  • For a wrong payload, the shape of the string you expected (WIFI:, wa.me, geo:, a review URL) without private values

Expect a reply within a few business days when a reply is possible. There is no on-call support and no same-day promise. A printed code that stopped scanning is not something email can patch remotely: the image already contains its payload. The usual fix is to generate a new file and replace the print. The password-change guide and why a QR stopped working cover the common cases before you write.

What a reply can and cannot do

  • Can: explain how a generator builds its string, point you at the matching tool or guide, and take a bug report about a page that rejects valid input or emits the wrong payload.
  • Cannot: look up a code you already generated, change a sticker that is already on a table, recover a password you did not save, or edit a Google, Telegram, Discord, or Zoom resource. Those stay with you and with that service.
  • Will not: count scans for you, or turn a static file into a dynamic redirect you can edit later. That is a different product. Reprinting is how a static code gets updated.

GitHub

Reproducible bugs and documentation fixes can also be an issue on the public repository: github.com/spook2406/qr-no-expire. Use email if the report includes anything you would not post in public. The repository is the source of the pages; it is not a hosted QR service.

Privacy requests

QR payloads are generated in your browser and are not uploaded to a qrstatic.app server. There is no account to delete and no stored history of the codes you made. Analytics and advertising are described in the Privacy Policy. For a privacy question, email smithk@gmail.com with “Privacy” in the subject line. Use of the tools is covered by the Terms of Use.

Before you write

Most “it expired” reports are a short link from another company, not a file from this site. If you still have the image, scan it and read the text it contains. A WIFI: line, a full https:// URL you recognize, or a mailto: came from a static generator. A short domain you do not control is a redirect, and only that vendor can restore it. How to tell static from dynamic walks through that check.

To make a new code, use the homepage generator or the guides for guest Wi‑Fi, Google reviews, and print size.
