# QRNoExpire — Free Static QR Code Generator

English static site: generate **permanent QR codes with no expiration and no signup**. All generation is client-side.

**Live:** https://spook2406.github.io/qr-no-expire/

## Features
- URL, text, WiFi, email, phone payloads
- PNG + SVG download
- Size, error correction, colors
- SEO guides targeting “no expiration / free forever / static vs dynamic”
- Privacy-first: no server upload of QR data

## Library
Bundled browser build of [`qrcode`](https://github.com/soldair/node-qrcode) (MIT). See `vendor/LICENSE-qrcode.txt`.

## Deploy
GitHub Pages from `main` / root. Includes `.nojekyll`.
