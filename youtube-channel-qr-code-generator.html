Which links are accepted

The host, after www is removed, must be youtube.com, m.youtube.com (rewritten to youtube.com), or youtu.be. http becomes https. The hash is dropped. Tracking parameters si, feature, pp, utm*, fbclid, gclid, and ab_channel are removed. The public path stays:

  • https://youtube.com/@yourchannel — a public channel handle
  • https://youtube.com/channel/UCxxxxxxxxxxxxxxxxxxxxxx — a public channel id
  • https://youtube.com/c/YourName — a public custom URL
  • https://youtube.com/user/YourName — a public legacy user URL
  • https://youtube.com/watch?v=VIDEO_ID — one public video
  • https://youtu.be/VIDEO_ID — the same video, short host
  • https://youtube.com/shorts/VIDEO_ID — one public Short

You may omit https://. These examples are shapes, not real pages. A channel tab such as /videos or /about is kept. A start time t= on a single video is kept.

What is rejected

Empty input is an error. music.youtube.com is rejected: this page does not do YouTube Music login or redemption. studio.youtube.com is rejected. Login, account, and signed-in library pages are rejected. TV and device pairing links, including /activate and a bare pairing code, are rejected. Authenticator and 2FA flows are rejected. A playlist URL that has list= and no video id is rejected and explained; paste the single video if that is what you want printed. Other websites, shorteners, and any short link or redirect on qrstatic.app are rejected, because this page does not follow redirects. None of those are silently encoded.

A scan does not make a private video public, and it does not bypass a copyright limit. If the page is limited to signed-in viewers, or the video is blocked, YouTube still enforces that. This tool does not bypass visibility settings.

A channel code and a single-video code

A channel code opens the channel. Use it when the scan should land on the public @handle, the /channel/UC… id, the /c/… custom URL, or the /user/… URL. A single-video code opens one watch page, one youtu.be link, or one Short. They are different URLs. Pick the page you want the scan to open, then generate.

On a desktop, paste that URL, choose Generate, scan the preview with your own phone, then download PNG or SVG. The official mobile Share QR is a different object: it is drawn inside the YouTube app for someone nearby, and it is a poor fit for a poster because of the logo in the center and because you cannot download it as a print file from the desktop site.

If the handle changes, reprint

Reprint. The image stores the URL that was encoded. If you change the @handle, the old print still contains the old address. Generate a new PNG or SVG from the new public URL and replace the print. We cannot update a code that is already on paper. A code that uses /channel/UC… stores the channel id, which does not change when the handle does, so that print still opens the same channel.

What is the difference between a channel code and a single-video code?

A channel code opens the channel: an @handle, a /channel/UC… id, a /c/… custom URL, or a /user/… URL. A single-video code opens one video from a watch?v= link, a youtu.be link, or a Shorts link. The scan opens whichever URL you encoded.
